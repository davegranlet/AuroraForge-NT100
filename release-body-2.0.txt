AuroraForge NT100 2.0 - integrated main-app build for Windows x64 and Linux x64 with the WWE 2K19 to WWE 2K25/2K26 converter capability.

Version scheme: major releases are plain (1.8.0, 2.0, ...); every fix/update gets the next letter (2.0.a, 2.0.b, ...). Each download filename carries its version so you can tell exactly which day's work you have.

Linux: runs on GPU-less hosts such as VPS servers - software rendering is the default on Linux; set AURORA_FORGE_GPU=1 on desktop machines to re-enable hardware acceleration.

Protection: access is verified in-app on every release - active Patreon tier plus a linked Discord VIP role, two-tier check through the hardened hosted verifier (rev 2026-10-01-secure3). Every release embeds a fresh verification challenge bound through the whole sign-in flow.
