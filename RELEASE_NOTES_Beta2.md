# Aurora Forge Beta2

## Release Status

Beta2 is the integrated Aurora Forge main-app build. The main application owns access verification and launches the bundled converter with a short-lived verified session, so a signed-in user is not asked to authorize the converter again.

## Included

- Portable Windows Aurora Forge Beta2 application.
- WWE 2K19 to WWE 2K25 converter capability, launched from the main app.
- Consolidated project catalog and integrated tool hubs.
- Canadian-futuristic dark red, silver, and black shell and converter styling.
- Rebuilding coming-soon tutorial surface while the first-party workflow documentation is rebuilt.
- Compiled-only distribution for protected extraction components; source publication remains pending clearance.
