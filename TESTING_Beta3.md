# Aurora Forge Beta3 Testing

1. Download from https://auroraforge.live (Downloads) or this release page's links. Verify SHA-256 against `SHA256SUMS.txt`.
2. Extract `AuroraForge-NT100-v1.8.0-beta.1-Windows-x64.zip` (Windows) or `Aurora-Forge-v1.8.0-beta.1-Linux-x64.tar.gz` (Linux) to a writable folder.
3. Windows: launch the AuroraForge NT100 executable. Linux: `chmod +x` the binary and launch it; on VPS/headless hosts no extra flags are needed (software rendering is automatic).
4. Complete the main-app access check once (active Patreon tier plus your linked Discord VIP role).
5. Open the converter from Tools.
6. Confirm the converter reports that it was verified by Aurora Forge and does not request a second authorization.
7. Run only controlled test inputs and keep source templates and installed game archives unchanged.

Direct converter launches retain the fallback sign-in path for diagnostics. The supported Beta3 user flow begins in the main application.
