# Aurora Forge Beta2 Testing

1. Extract `Aurora-Forge-v1.8.0-beta.1-Windows-x64.zip` to a writable folder.
2. Launch the Aurora Forge Beta2 executable.
3. Complete the main-app access check once.
4. Open the converter from the Projects or integrated capability view.
5. Confirm the converter reports that it was verified by Aurora Forge and does not request a second authorization.
6. Run only controlled test inputs and keep source templates and installed game archives unchanged.

Direct converter launches retain the fallback sign-in path for diagnostics. The supported Beta2 user flow begins in the main application.
