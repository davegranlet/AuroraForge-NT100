Integrated Aurora Forge main-app build for Windows x64 and Linux x64 with the WWE 2K19 to WWE 2K25/2K26 converter capability.

Downloads (big files are self-hosted at auroraforge.live/downloads):

- Windows - main app: https://auroraforge.live/downloads/AuroraForge-NT100-Beta3-Windows-x64.zip
- Linux - main app (GPU-less OK): https://auroraforge.live/downloads/AuroraForge-NT100-Beta3-Linux-x64.tar.gz
- Windows - converter only: https://auroraforge.live/downloads/Aurora-Forge-Beta3-Preview.exe
- Linux - converter only: https://auroraforge.live/downloads/Aurora-Forge-Beta3-Preview.tar.gz
- SHA-256 hashes: https://auroraforge.live/downloads/SHA256SUMS.txt

This release page is the public mirror; the SHA-256 sums are attached below (SHA256SUMS.txt) and published at the downloads URL above.

Linux: runs on GPU-less hosts such as VPS servers - software rendering is the default on Linux; set AURORA_FORGE_GPU=1 on desktop machines to re-enable hardware acceleration.

Protection: access is verified in-app on every release - active Patreon tier plus a linked Discord VIP role, two-tier check through the hosted Patreon verifier. Every release also embeds a fresh random verification challenge that the verifier echoes back; stored sessions are bound to it, so a session or cracked build for one release does not unlock the next.

See RELEASE_NOTES_Beta3.md and TESTING_Beta3.md in this repository for details. Independent modding software; contains no copyrighted game assets.
