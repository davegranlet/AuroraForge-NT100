Aurora CAK Foundry

Rebuild an extracted mod folder into a game-ready CAK

Extract files above, edit them without changing their relative paths, then choose that output folder here. Aurora Forge uses the selected game's FDIR profile when rebuilding.

WWE 2K26 uses the selected output filename when deriving its v9.9 archive key, so do not rename a finished 2K26 CAK. WWE 2K25 uses its separate v9.3 build profile.

A supplied _textures.tdb is preserved for raw WWE 2K25 rebuilds. WWE 2K26 retains its existing version-6 texture-database handling.

WWE 2K25 CAK Loader

Check, enable, or restore the loader

This is separate from baking and from choosing mods. Foundry supports only reviewed WWE 2K25 builds (Saturday Night's Main Event and v1.23), checks every loader-file checksum, and backs up existing loader control files before an explicit enable. It never copies or enables a mod CAK.

Check the loader status before making any change.

Important

Original game archives remain read-only

Aurora Forge never changes the selected CAK. Extract All runs only when every stored payload has a confirmed genuine virtual path. If even one filename remains unresolved, the operation stops before writing payloads and reports the coverage problem. An external reference cannot be extracted from the selected CAK because that catalog record contains no payload bytes. Keep extracted game assets for personal modding and do not redistribute copyrighted game content.
