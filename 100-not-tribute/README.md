# 100% Not TRIBUTE

The complete feature-for-feature replacement for TRIBUTE, incorporated inside
AuroraForge NT100. Not to be confused with the NT100 Creation Suite — that is
Aurora's own creator workflow; this section is the Tribute-replacement set.

**Status:** consolidation in progress. The goal is one package: every
Tribute-related editor and creation suite merged into the single NT100 app.
