AuroraForge NT100 2.0.a - integrated main-app build for Windows x64 and Linux x64 with the WWE 2K19 to WWE 2K25/2K26 converter capability.

Highlights in 2.0.a:
- CAK Foundry multi-version support: pick your game in the extractor (WWE 2K20-2K26, auto-detect default). 2K25 archives open through the bundled native FDIR 9.3 backend, 2K22/2K23/2K26 through the built-in readers, and 2K19 is handled by the PAC Explorer.
- Converter now reads "WWE 2K19 -> 2K26 Entry Forge" (2K25/2K26 targets supported).
- Bundled 2K26 registration skeleton restored.
- Verifier rev 2026-10-01-secure4: /health shows a live Discord probe (bot + guild).

Version scheme: major releases are plain (2.0, 2.1, ...); every fix/update gets the next letter (2.0.a, 2.0.b, ...). Each download filename carries its version.

Linux: runs on GPU-less hosts such as VPS servers - software rendering is the default on Linux; set AURORA_FORGE_GPU=1 on desktop machines to re-enable hardware acceleration.

Protection: access is verified in-app on every release - active Patreon tier plus a linked Discord VIP role, two-tier check through the hardened hosted verifier. Every release embeds a fresh verification challenge bound through the whole sign-in flow.
