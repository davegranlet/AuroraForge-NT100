# Aurora Forge 2.1.a - Beta 4 Update

## Free Release Update

This update collects the work completed since 2.1 Beta 4.

### Highlights

- **License:** Aurora Forge source is now GPL-3.0-or-later. Third-party components keep their own licenses.
- **Public source mirror:** updated GitHub source and website source archives.
- **Website:** refreshed, less cluttered copy and clearer download/source paths.
- **FAQ:** rewritten for the current app, supported games, source, and support model.
- **Animation converter:** full 2K19 to 2K20 / 2K22 / 2K23 / 2K24 / 2K25 / 2K26 matrix and visible target selector.
- **Converter labels:** required source/target/output fields are labeled.
- **Loader source:** Secure DataCtrlLink and CAK Mod Loader source trees.
- **Animation toolchain:** the current conversion, codec, ADefs, SDB, pair-table, and validation tools.
- **CAK Foundry:** current bake, reader, repackager, and verification source.
