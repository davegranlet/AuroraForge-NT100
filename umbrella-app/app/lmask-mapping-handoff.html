Mapping Handoff Prompt Builder

Use this after the user already has an approved luchador mask design image. AuroraForge NT100 loads mapping profiles from /profiles/lmask/profiles.json, previews the selected profile zones, and builds prompts that either embed profile data or clearly tell the user to upload the profile JSON.

Important: Profile name alone is not enough with your chosen compatible AI tool. Use Full/Compact mode to embed the profile, or use Upload profile file and upload the JSON profile with the approved image.
Tip: For regular projects, use Luchador Mask Studio to save settings and download a complete handoff pack. This page is the direct mapping-prompt builder.
