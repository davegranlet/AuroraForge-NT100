Cole Quinn Face Layout Reference Legend

Purpose:
This file explains the matching layout PNG and 128x128 technical grid PNG. Upload the layout PNG with the Face Texture Prompt, selected profile JSON, and stock character head_color texture.

Rules:
- The layout reference is a placement guide only.
- Do not copy guide colors, labels, or grid lines into the final face texture.
- The stock character head_color texture remains the visual authority for the exact lower neck / UV padding footprint.
- The final generated face texture must be 2048 x 2048 unless a different project size is explicitly selected.
- Lower neck / upper chest UV padding is opaque texture space, not transparency.

128x128 grid:
Each grid cell equals exactly 16 px on a 2048 x 2048 texture.
Heavy grid lines appear every 16 cells, matching 256 px blocks.
