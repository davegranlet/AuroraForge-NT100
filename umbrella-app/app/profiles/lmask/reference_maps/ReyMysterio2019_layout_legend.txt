Rey Mysterio 2019 Luchador Mask Layout Legend

Purpose:
Upload this layout reference with the final handoff prompt, selected profile JSON, and bundled/default mask texture.

Rules:
- The layout reference is a placement guide only.
- Do not copy guide colors, labels, or grid lines into the final mask texture.
- The default/stock mask texture remains the visual authority for the exact UV footprint.
- Final production outputs are mask_color.png, mask_mask1.png, and mask_nrm.png.
- Default production canvas is 2048 x 2048.

128x128 grid:
Each grid cell equals exactly 16 px on a 2048 x 2048 texture.
Heavy grid lines appear every 16 cells, matching 256 px blocks.

Zones:
- full_canvas: columns 1-128, rows 1-128 — Full mask_color canvas; keep 2048 x 2048 square.
- background_padding: columns 1-128, rows 1-128 — Dark/opaque UV padding and non-feature areas. Do not make transparent unless the actual source alpha proves it.

- left_eye_opening_zone: columns 27-43, rows 45-61 — Left eye/opening and trim-safe zone.
