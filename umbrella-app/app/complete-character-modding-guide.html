AuroraForge NT100 · Beginner Path

Build a Complete WWE 2K26 Character

CakeHook → CakeView → AuroraForge NT100 → Tribute → in-game testing.

Back to Tutorials
Start with an empty project. Finish with a tested character.

Do one numbered job. Do not skip the check.

This guide uses plain language. It covers a new roster slot, original face and body textures, original attire, a legal custom theme, moveset, entrance, victory, render, baking, and final testing.

01

Install CakeHook

CakeHook is the loader that lets WWE 2K26 use enabled mod files.

  1. Close WWE 2K26.
  2. In Steam, right-click WWE 2K26, choose Manage, then Browse local files.
  3. Download the current WWE 2K26 CakeHook package from the official Pro Wrestling Mods source.
  4. Open the package. Copy its dinput8 file and Plugins folder into the folder beside the WWE 2K26 executable.
  5. Do not copy an older game’s CakeHook into WWE 2K26.
  6. Launch the game once with no character mod installed. Reach the main menu, close the game, and write down whether it worked.
Pass: the clean game reaches the menu and the CakeHook files remain in the correct game folder.
Stop: the game crashes before the menu. Remove the new CakeHook files, restore your clean folder, and obtain the current compatible release.
02

Install and connect CakeView

CakeView explores supported game files, previews models/materials, and bakes prepared content.

  1. Install the current CakeView 26 release from Pro Wrestling Mods.
  2. Open CakeView and select the WWE 2K26 executable when asked.
  3. Confirm that CakeView can open the game’s file explorer.
  4. Create a temporary empty bake test. Do not start with your real character.
  5. Leave silent baking and directory watching off until a manual bake works.
  6. Add CakeView’s location in AuroraForge NT100 Setup so it is easy to open later.
Pass: CakeView recognizes WWE 2K26 and can browse supported files.
03

Install and connect Tribute 26

Tribute manages roster/default data, slots, profiles, movesets, entrances, victories, themes, renders, and related records.

  1. Install the current Tribute 26 release from its official source.
  2. Open Settings.
  3. Choose the WWE 2K26 game directory and the correct save location.
  4. Choose CakeView if the current version provides that setting.
  5. Keep Auto-Bake off for the first project.
  6. Confirm the status area reports a usable BakeMe state.
  7. Back up Tribute’s working/default-data folders before creating a record.
Pass: Tribute opens, its folders point to WWE 2K26, and the main managers load.
Stop: Tribute points to another WWE game, another Steam account, or an unknown save folder.
04

Make a safe project

  1. Enter the character name below and select Create Complete Character Project.
  2. AuroraForge NT100 creates 00_Backups, 01_References, 02_Model, 03_Textures, 04_Attire, 05_Audio, 06_Profiles_JSON, 07_Ready_To_Bake, 08_Test_Builds, and 09_Screenshots.
  3. Copy your save backup and untouched source files into 00_Backups.
  4. Never edit the only copy.

Pass: you can delete the entire Work area and still restore the original from Backups.
05

Plan the complete character

  1. Open AuroraForge NT100 Creative Studios → Complete Character.
  2. Write the roster name, entrance name, height, weight, class, hometown, crowd reaction, and visual theme.
  3. Choose a new Tribute slot. Use an existing-slot replacement only when you understand exactly what it replaces.
  4. Plan ring attire and entrance attire separately.
  5. Plan the face, hair, tattoos, logos, materials, theme music, moveset, entrance, victory, render, and graphics.
  6. Save the project brief before making any asset.
Confirmed for Tribute 26’s initial release: 732 new character slots and up to 25 attire slots per character were announced. Check current Tribute release notes before relying on those numbers.
06

Choose a safe model base

A new character normally begins from a known-working WWE 2K26 character structure that matches the body/skeleton category you need.

  1. Download the AuroraForge NT100 reference-model library from the current VikingStudios Discord link.
  2. Select Open Reference Models Folder and place the downloaded MCDS and MTLS contents in their matching folders.
  3. Choose the supplied reference point that matches the body/skeleton category you need.
  4. Record every folder, model, material, and texture name before changing anything.
  5. Keep the skeleton, required mesh names, UV maps, material slots, and model scale unless verified documentation says otherwise.
  6. Build original geometry or use assets you are allowed to modify.
  7. Test the base body before adding hair and clothing.

Stop: you do not know which skeleton/body category the source uses, exported UVs changed, or model import reports missing parts.
07

Make the face and body textures

  1. Copy the original target DDS files into Backups.
  2. Open AuroraForge NT100 Face Texture Studio and choose the correct face profile.
  3. Build a square face texture from permission-cleared references.
  4. Use Tattoo and the other Creative Studios for body art and logos.
  5. Compare your output to the stock texture layout. The stock UV footprint is the authority.
  6. Keep required padding and do not paint a normal portrait onto a UV texture.
  7. Save editable PNG masters in 03_Textures.
Pass: the face features and body art occupy the same UV regions as the working stock texture.
08

Convert DDS and PNG without Photoshop

Open AuroraForge NT100 Tools → DDS Converter. The converter is included in the Windows app and AuroraForge NT100 handles its commands internally.

DDS → PNG

  1. Press DDS → PNG.
  2. Press Choose DDS Files, or press Convert a DDS Folder to process every DDS in one folder.
  3. Choose a separate output folder when asked.
  4. Press Convert Files if you selected individual files. Folder conversion starts automatically.
  5. Open the result and make sure it is not blank or the wrong size.

PNG → DDS

  1. Press PNG → DDS.
  2. Press Choose PNG Files, or press Convert a PNG Folder.
  3. Choose a separate output folder.
  4. Choose the folder containing the untouched, same-name original DDS files. AuroraForge NT100 uses those originals to match format, dimensions, and mipmaps.
  5. Use the manual fallback only when you have verified the correct format and no matching original exists.
  6. Press Convert Files if you selected individual files. The folder workflow converts automatically after its folders are chosen.
  7. Review the conversion report and compare the new DDS with the original.
Important: Never assume a color map, normal map, or mask uses the same DDS format. Let AuroraForge NT100 match each file to its working original whenever possible.
Pass: filename, dimensions, format, alpha behavior, and mipmaps match the target.
Stop: the converted texture is black, loses transparency, changes size, or reports a different format than the stock target.
09

Build original attire and hair

  1. Start from a compatible, known-working attire/hair structure.
  2. Create or legally obtain the model assets.
  3. Preserve the required skeleton binding, material slots, scale, and UVs.
  4. Make color, normal, and packed mask textures to match each original target’s dimensions and DDS format.
  5. Keep ring and entrance attire easy to identify.
  6. Use CakeView’s preview to check missing meshes, reversed normals, transparency, and material links.
  7. Test one piece before adding the next.
Stop: clothing explodes during poses, hair floats, a mesh is invisible, or a body part disappears unexpectedly.
10

Assemble the character folder

  1. Copy the known-working folder structure into Work.
  2. Replace only the intended model, material, and texture files.
  3. Keep exact filenames unless the supported workflow also updates every reference.
  4. Use AuroraForge NT100 Mod File Inspector to compare Original and Modified.
  5. Confirm that MCD, MTLS, JMTL, YCL, and DDS references are present where expected.
  6. Do not hex-edit an unknown binary because a filename looks readable inside it.
  7. Put the checked folder into 07_Ready_To_Bake.
Pass: the comparison report contains only changes you intended.
11

Create the character record in Tribute

  1. Open Easy Wizard or Create Character.
  2. Load a trusted profile JSON, or enter Profile A and Profile B manually.
  3. Check name, gender/category, height, weight, class, hometown, announcer ID, and crowd settings.
  4. Choose a new slot for a first project. Treat Replace as advanced.
  5. Select the prepared character folder and render DDS.
  6. Do not create the record until every path is correct.
  7. Save/export the character profile JSON into 06_Profiles_JSON.
Protect default data: keep Tribute’s BakeMe/default profile data current. Game-save data can change when you edit in-game or when a save is replaced. Reusable JSON/default profiles make recovery easier.
12

Add the moveset

  1. Begin with a moveset template that fits the character’s style.
  2. Change signatures, finishers, taunts, strikes, grapples, running moves, aerial moves, reversals, and recovery behavior.
  3. Test for unavailable, duplicated, or unsuitable moves.
  4. Export/save the moveset as default data or JSON when supported.
  5. Link the correct moveset profile to the new character.
  6. Keep a copy outside the game save.
Pass: the character can complete a normal match and all signatures/finishers trigger correctly.
13

Add entrance, victory, music, and graphics

  1. Open Tribute’s entrance/template tools.
  2. Choose the normal entrance, title entrance, double-title entrance, MITB entrance, victory, music ID, and GFX template.
  3. Save as a new template instead of overwriting an unrelated one.
  4. Use only music you own or may use.
  5. Prepare the theme with the current SoundFactory/audio workflow. Audio codecs, IDs, and import steps are version-sensitive, so follow the current PWM SoundFactory instructions.
  6. Assign the verified theme ID in the character’s entrance/template data.
  7. Prepare the render, nameplate, trons, and other graphics, then link only IDs you have verified.
  8. Export/save entrance and victory default-data profiles when supported.
Current community tool note: recent WWE 2K26 tutorials use SoundFactory for custom themes. Use the current release and its own instructions rather than an old WWE 2K25 conversion recipe.
14

Make the first manual bake

  1. Close WWE 2K26.
  2. Open CakeView.
  3. Stage only the new character and required profile changes.
  4. Read CakeView’s summary before baking.
  5. Create a named test build.
  6. Bake manually.
  7. Save the build log or screenshot.
  8. Do not turn on Auto-Bake until this manual build works.
Pass: CakeView completes without an error and you know exactly which files entered the bake.
15

Test the whole character

  1. Launch the game.
  2. Confirm the new roster entry and render.
  3. Start a plain one-on-one match in a normal arena.
  4. Check the face close up, skin tone, eyes, mouth, body art, hair, ring attire, entrance attire, transparency, shine, and normals.
  5. Perform running, crouching, corner, rope, ground, signature, and finisher animations.
  6. Test entrance, theme start and volume, trons/GFX, ring announcement, title entrance, and victory.
  7. Test both attire slots.
  8. Check an unrelated stock character to make sure it was not changed.
  9. Take front, side, back, and action screenshots.
Pass: the new character works from roster selection through victory without changing unrelated content.
16

Fix one problem at a time

ProblemCheck first
Game crashes before menuCakeHook/game-version compatibility; remove the last loader/plugin change.
Character is missingSlot/profile creation, default-data bake, and the exact character folder.
Black or invisible meshMissing texture/material, wrong DDS format, alpha, model/material assignment.
Face is stretchedWrong face profile, UV layout, or target stock texture.
Clothing explodesSkeleton weights, model category, import/export process.
Theme is silentSoundFactory import, assigned ID, audio format, entrance template.
Wrong movesetLinked moveset profile and baked/default data.
Old version remainsWrong bake target, duplicate mod, stale output, or loader path.
  1. Write the problem in one sentence.
  2. Restore the last working build.
  3. Change one file or one record.
  4. Bake and repeat the same test.
  5. Keep the change only if it fixed the problem.
Finish line

Archive the working character

Save the final character folder, source files, profile JSON, moveset, entrance/victory data, audio source and permission note, bake report, tool versions, screenshots, and a clean restore package. Never distribute extracted stock assets.
