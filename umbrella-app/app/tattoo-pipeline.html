Tattoo file notes

Tattoo support files

For tattoos, the support files are created alongside the main tattoo image: main_tattoo.png, design_mask.png, and design_blur.png. These are working PNG files that can later be converted to DDS.

design_mask.png
Black-and-white tattoo visibility mask. White or light grey marks the visible tattoo area; black marks hidden/transparent space.
design_blur.png
Softened blur/falloff file aligned to the tattoo mask. Used to reduce harsh sticker edges and help the tattoo blend cleanly.
