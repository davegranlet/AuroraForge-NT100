Current safety limits

Unsupported writes stay unavailable

This release rebuilds existing entries through HSPC and SHDC containers. It does not add entries, overwrite the selected PAC, rebuild BPE data, or write through EPAC, EPK8, and PACH parents. BPE entries can still be copied out in their original compressed form.

WWE 2K20 is a separate CAK-based target. Use the WWE 2K20 CAK Workbench to check the install and track extractor/rebuilder readiness.
