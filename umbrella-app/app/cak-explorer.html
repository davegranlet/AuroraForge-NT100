Aurora CAK Foundry

Rebuild an extracted mod folder into a game-ready CAK

Extract files above, edit them without changing their relative paths, then choose that output folder here. AuroraForge NT100 excludes the selected folder's own name and rebuilds its contents as a protected WWE 2K26 FDIR archive.

The saved .cak filename is part of WWE 2K26's encryption key. Aurora derives the correct v9.9 key from the final filename automatically, so you may choose any name—but do not rename the CAK after building it. Rebuild it under the new name instead.

_textures.tdb is not baked into separate mod CAKs. Texture replacements rely on existing metadata so multiple active mods do not fight over duplicate root texture databases.

No BakeMe folder selected.

The source folder stays unchanged. The rebuild uses hashed virtual paths, protected payloads, FDIR v9 metadata, and independent byte-for-byte recovery checks.

Important

Original game archives remain read-only

AuroraForge NT100 never changes the selected CAK. Every confirmed path is built into the release. A payload with an unknown name can still be extracted into an Unresolved folder under a generated hash name. An external reference cannot be extracted from the selected CAK because that catalog record contains no payload bytes. Keep extracted game assets for personal modding and do not redistribute copyrighted game content.
