PART ONE / FIRST INSTALL

Put the app on your PC.

The Windows download is one installer file. It installs the app and, if you leave the box checked, the loader files. It does not install anything into your game without asking which game folder to use.

1

Get the installer from the website.

Open auroraforge.live. Click the red Windows x64 .exe button. The current file is named AuroraForge-NT100-Setup-2.1.9-x64.exe.

  • Use the website, not a random file-sharing link.
  • If you want to check it, the SHA-256 link is next to the download.
2

Open the file and choose your game folder.

In your browser, open the download when it finishes. If you use File Explorer, go to Downloads and double-click AuroraForge-NT100-Setup-2.1.9-x64.exe.

Windows may ask for permission. Choose Yes. If you see a blue SmartScreen warning, click More info, then Run anyway. The installer is not code-signed yet, so Windows does not know the publisher.

The installer then asks for the folder containing WWE2K26_x64.exe. Click Browse... and choose that folder. It is usually under SteamLibrary\steamapps\common\WWE 2K26.

Do not use “Extract” on the .exe. Double-click it. It is an installer, not a ZIP file.
3

Choose the loader option, then finish.

Leave Install Secure DataCtrlLink, CAK Mod Loader, and Custom Music Loader checked if you want the loader package. Clear it if you only want the app.

The installer backs up the files it replaces. It does not delete mods, CAKs, manifests, or sound packages. Leave Run AuroraForge NT100 checked and click Finish.

The app opens in one window. Click Start a project or use the sidebar. Your projects and settings stay on your PC when you close it.

On Linux: download the Linux x64 .tar.gz, extract it, and run the AuroraForge NT100 executable. The Linux build starts in software rendering on machines without a GPU. There is no Windows-style installer.

PART TWO / UPDATING THE APP

Let the app update itself.

The installed app checks GitHub Releases for a newer build. You do not need to delete the old app first. Projects, settings, and the loader stay where they are.

Close WWE 2K26 first if the update installs loader files. The installer refuses loader changes while the game is running. The app can still download the update while the game is closed.
5

Click Help, then Check for Updates.

Open AuroraForge NT100. At the top of the window, click Help. Click Check for Updates.... The app asks GitHub whether a newer version exists.

If you are already current, it says so. If a newer version exists, a box like the picture appears.

6

Download, then restart.

Click Download update. When the download finishes, the app asks you to restart. Click Restart and install.

The app closes for a moment. The installer runs, then the app opens again on the new version.

7

Close the update installer.

The update installer may ask for the game folder again. It should remember the path. Check it, leave the loader box set the way you want, then click Close or Finish.

Open the app and check the build number in the About page or the build chip. This guide is written for 2.1.9 Beta 4.

If Check for Updates says you are current: you already have the newest version. If you want to reinstall or move to another PC, use the website download. Installing over the old app is safe for projects and settings.

IF SOMETHING GOES WRONG

Small problems,
simple answers.

Most install problems are Windows trust prompts, a missing game folder, or WWE 2K26 still running. The app does not need Node, npm, Python, or a command window.

Windows says “unrecognized app”

Click More info, then Run anyway. The installer is currently unsigned. Verify the SHA-256 from the website if you want to check the file first.

It says WWE 2K26 is running

Close the game completely, then try the loader install or update again. The app can be open while you download the update, but the game should be closed when loader files are replaced.

I cannot find WWE2K26_x64.exe

Open Steam, right-click WWE 2K26, choose Manage, then Browse local files. Use that folder. Do not choose the folder above it.

I do not want the loader

Clear the loader checkbox before closing the installer. The app still installs normally. You can add the loader later by running the installer again.

I need to update but the app says it is current

You are already on the latest build. If you need to repair the install, run the current installer from the website over the old one. Projects and settings are kept.

Where are the source and older builds?

Source is on the Source page. Public builds are on the Downloads page. The GitHub Releases page carries the updater files and release notes.
