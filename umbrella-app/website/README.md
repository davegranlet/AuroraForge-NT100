# AuroraForge NT100 Live Site

This folder is a self-contained static website for `auroraforge.live`.

## Upload

Upload the contents of this folder directly into cPanel's `public_html` directory. The folder itself should not become `public_html/website`; `index.html` needs to sit at the public web root.

The download buttons point at the self-hosted files in the `downloads/` folder (upload that folder's contents to `public_html/downloads/`). The GitHub Beta3 release stays as the public mirror. Big binaries in `downloads/` are intentionally gitignored so the site source stays text-only.
