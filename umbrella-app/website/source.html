BOUNDARIES

WHAT IS NOT INSIDE.

Source downloads are public source only. Source is licensed under GPL-3.0-or-later; third-party components keep their own licenses. Game data, retail files, binaries, private research, the private verifier, and the website source are excluded. The archives for the main app and tools include their build metadata; platform tools such as .NET, Python, and Java are not bundled.

Some workflow archives contain deep paths. Extract with 7-Zip or enable Windows long-path support if your extraction folder is deeply nested.
